# Product Analytics Interview Prep Handbook

Welcome to the **Product Analytics Interview Prep Handbook**! This comprehensive guide is designed to help you ace data science and product analytics interviews.

## Overview

This handbook provides a structured 3-week curriculum covering:

- **Week 1: Core Skills** - SQL, Python, and Statistics fundamentals
- **Week 2: Product Thinking & A/B Testing** - Product sense, metrics, and experimentation
- **Week 3: Execution & Interviews** - Mock interviews, behavioral prep, and final polish

## How to Use This Guide

1. **Follow the weekly structure** - Each week builds on the previous one
2. **Complete exercises and projects** - Hands-on practice is essential
3. **Review and synthesize** - Each week includes review sessions
4. **Practice with mock interviews** - Prepare for real interview scenarios
